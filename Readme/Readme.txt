# 🎬 DVD Rental BI Dashboard (PostgreSQL + Metabase)

## 📌 Project Overview

This project is an end-to-end **Business Intelligence (BI) solution** built using the classic DVD Rental dataset. It demonstrates how raw relational data can be transformed into meaningful business insights using **SQL, PostgreSQL, and Metabase**.

The goal was to design and build an interactive analytics dashboard that supports data-driven decision-making through key performance indicators (KPIs), trend analysis, and performance insights.

## 📊 Key Business Insights

The dashboard provides insights into:

- Total Movies, Customers, Rentals, and Revenue (KPIs)
- Distribution of movies by rating (G, PG, PG-13, R, etc.)
- Categorization of movies across different genres
- Top 5 most rented films
- Revenue contribution per film
- Rental activity patterns across the dataset
